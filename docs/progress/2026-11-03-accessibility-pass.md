# Accessibility pass — 3 Nov 2026

## Findings
- Voice-first helps users who cannot read comfortably, which is the main audience.
- Visual feedback for the orb and waveform should also work with reduced motion.
- Text fallback is useful when audio quality is poor.

## Changes to consider
- Larger tap targets on the frontend controls.
- Visible labels alongside icons.
- Respect reduced-motion settings for the waveform animation.

## Open questions
- How the experience degrades on a low-bandwidth call.
- Whether to support a screen-reader-friendly transcript view.
